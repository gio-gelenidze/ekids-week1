# Java For Kids - Week 1 Assignments

Two simple coding challenges to learn if/else statements.

---

## 📋 Assignment 1: Even or Odd

**What to do:**
- Open: `src/main/java/com/ekids/week1/EvenChecker.java`
- Find the `TODO` comment
- Write an `if/else` that prints `even` for even numbers and `odd` for odd numbers


---

## 🧟 Assignment 2: Minecraft Mob Reactions

**What to do:**
- Open: `src/main/java/com/ekids/week1/MobReaction.java`
- Find the `TODO` comment
- Write an `if/else` that:
  - Prints `run` when user enters "creeper"
  - Prints `attack` when user enters "zombie"
  - Prints `stay` for anything else


---

## ✅ How to Check Your Work

Run the tests to see if your code works:

```bash
mvn test
```

If tests pass, you're done! 🎉

---

## 🎮 Run Your Program

After you finish an assignment:

```bash
mvn package
java -cp target/even-assignment-1.0-SNAPSHOT.jar com.ekids.week1.EvenChecker
```

Or for Mob Reactions:

```bash
java -cp target/even-assignment-1.0-SNAPSHOT.jar com.ekids.week1.MobReaction
```

Type an answer and press Enter to see your program work!
